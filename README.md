## 📌 Overview

Mental Wellness Tracker helps users monitor their emotional health by tracking daily moods, stress levels, and behavioral patterns.  
It provides visual insights through charts and a calendar-based mood map.

---

## ✨ Features

- 😊 Daily Mood Tracking  
- 😰 Stress Level Monitoring (1–10 scale)  
- 📊 Interactive Charts (Chart.js)  
- 📅 Calendar Mood Visualization  
- 🔥 Streak Tracking  
- 💡 Smart Suggestions  
- 📈 Mood + Stress Combined Analytics
